# The Polydance name and mark

The code is open source ([LICENSE](LICENSE)). The name **Polydance** and the ballerina mark
(`app/android/app/src/main/res/drawable-nodpi/polydance_mark.png` and the icons drawn from it by
`design/icons.py`) are not covered by either licence. The Apache License says so itself in section 6.

Polydance records people's rooms and voices. People trust a recorder because of who made it, so the name
stays with the builds and the service its makers stand behind.

**You may, without asking:**

- Say truthfully that your work is based on Polydance, works with Polydance, or reads Polydance bundles.
- Build the code unchanged for yourself or your team, and run your own receiver, and call it Polydance
  inside your team.
- Use the name in articles, reviews, talks and tutorials about Polydance.

**Ask first, or rename:**

- Anything you distribute that is changed from this repository, or run as a service for other people:
  give it another name and another icon, and change the package ids (`net.polydance.capture`,
  `net.polydance.capture.mac`) so it cannot be mistaken for, or install over, an official build.
- Store listings, domains or accounts that use the name or the mark.

Questions: the contact on the receiver's `/privacy` page.
